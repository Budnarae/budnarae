# 개요

본 문서는 크래프톤 게임 테크랩 2기를 이수하며 진행한 자체 게임 엔진 프로젝트를 정리한 문서이다. 본 프로젝트는 14주간 크래프톤 정글 캠퍼스에서 합숙하며 진행하였으며, 매주 주어지는 과제를 수행하며 엔진에 새로운 기능을 추가하는 방식으로 진행되었다.

모든 과제는 4인 팀 프로젝트로 수행되며, 매주 무작위로 팀 구성원이 바뀌게 된다. 따라서 자연스레 다양한 사람들과의 협업을 경험할 수 있었으며, 프로젝트 베이스 코드도 계속 바뀌기 때문에 코드 리뷰, 분석 능력을 기를 수 있었다.

다음은 각 주차의 과제 수행 내역을 정리한 것이다.
