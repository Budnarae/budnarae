# 개요

**주제**: Animation System & GPU Skinning

**목적**: 애니메이션 재생 시스템을 확장하고 CPU/GPU Skinning 전환 구조를 구현해 성능과 유연성을 함께 확보한다.

**과제**
- `Skeleton`, `SkeletalMesh`, `AnimSequence` 클래스 역할 분리
- Animation State Machine 구현
- `UAnimInstance`/`UAnimSingleNodeInstance` 구현
- GPU Skinning 구현
- CPU/GPU Skinning 성능 비교 Stat 구현
- 콘솔 명령어 기반 CPU/GPU Skinning 전환
- Reverse Play Animation 구현(음수 PlayRate 포함)
- Lua 기반 Animation State Machine 구현

**학습 키워드**:
- Animation State Machine
- GPU Skinning
- Animation Instance
- Reverse Playback
- Lua-driven Animation
