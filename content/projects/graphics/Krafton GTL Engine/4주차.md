# 개요

**주제**: Static Mesh & Multi Viewport

**목적**: 정적 메시 렌더링 파이프라인과 에디터 다중 뷰포트 구조를 구현해 에디터 확장성과 리소스 운용 기반을 강화한다.

**필수 과제**
- StaticMesh 구현 및 렌더링
- OBJ 리소스 로드 및 에셋 할당(프로퍼티 연동)
- StaticMesh Transform 조작 지원
- StaticMesh 전용 셰이더(`StaticMeshShader.hlsl`) 적용
- 다중 재질(Section) 지원
- 4분할 다중 뷰포트 및 스플리터 구현
- Perspective/Orthogonal 뷰 동시 렌더링
- 뷰포트/카메라 정보 `editor.ini` 저장·복원

**선택 과제**
- OBJ 파싱 결과 바이너리 Bake
- Overlay Stat 렌더링(`stat fps`, `stat memory`, `stat none`)

**학습 키워드**:
- Resource Pipeline
- Static Mesh
- Multiple Material(Section)
- Multi Viewport
- FViewport / FViewportClient
- OBJ Parsing & Binary Bake
- Editor Serialization
