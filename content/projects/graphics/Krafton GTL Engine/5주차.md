# 개요

**주제**: Game Jam 2nd - Brute Force Competition

**목적**: 대규모 StaticMesh 씬에서 병목 지점을 분석하고, 실시간 조건을 만족하는 렌더링/피킹 성능 최적화 역량을 강화한다.

**과제**
- 표준 리소스(`JungleApples.zip`, `DefaultScene.zip`) 기반 대규모 씬 테스트
- 화면 좌상단 퍼포먼스 오버레이 출력
- FPS 및 프레임 시간(ms) 측정/표시
- Picking 1회 소요 시간(ms) 및 누적 횟수/누적 시간(ms) 측정
- 표준 씬 변경에도 동작 가능한 실시간 최적화 적용
- 캐시 의존 정지 화면 최적화 금지 조건 준수
- 오브젝트/카메라가 실시간으로 변하는 상황 가정 성능 유지

**학습 키워드**:
- Bottleneck Analysis
- Real-time Optimization
- Performance Profiling
- Picking Performance
- Massive StaticMesh Scene
