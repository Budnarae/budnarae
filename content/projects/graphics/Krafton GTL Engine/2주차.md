# 개요

**주제**: Break into 3D in 2D Space

**목적**: 2D에서 3D로 확장되는 공간 개념을 바탕으로 투영/카메라/좌표계 변환을 실제 편집기 기능과 렌더링 기능으로 구현한다.

**필수 과제**
- 프리미티브 생성 및 배치
- 2D 마우스 좌표의 3D 변환 기반 오브젝트 선택
- Gizmo 및 Property 창 기반 Transform(Location/Rotation/Scale) 조작
- World/Local Axis 렌더링
- 카메라 이동
- 씬 JSON 저장/불러오기
- UObject 기반 코어 시스템 구현 시작

**선택 과제**
- Console Window(ImGui) 구현
- UUID 발행/관리 시스템 구현
- Heap 메모리 추적(할당량/할당 횟수) 구현
- UObject RTTI 및 Object Factory 구현
- UE 스타일 컨테이너/이름 체계(FName 등) 정리

**학습 키워드**:
- MVP(Model-View-Projection)
- Local/World/View/Projection Space
- Homogeneous Coordinates(FVector4)
- Vertex Shader 상수 버퍼
- ImGui 기반 에디터 UI
