# 개요

**주제**: Editor & Rendering (눈에 보이는 세상)

**목적**: 에디터 사용성과 디버깅 가시성을 높이는 렌더링 보조 기능을 구현하고, 씬 관리 기반을 확장한다.

**필수 과제**
- Billboard 문자열(텍스처 아틀라스 기반) 렌더링
- UUID 오버레이 표시/토글
- Batch Line 렌더러 구현(Vertex/Index Buffer 통합 관리)
- World Grid 및 AABB 렌더링
- Scene Manager 구현
- 좌표계 변환(D3D -> UE)
- 윈도우 리사이즈 대응
- View Mode(Wireframe 포함) 전환
- Show Flag 기반 프리미티브 토글
- 카메라 감도 조절 및 `editor.ini` 저장/복원

**선택 과제**
- FName 기반 문자열 테이블/풀링 구조 적용
- ASCII 외 한글 문자열 렌더링
- SubUV 기초 적용

**학습 키워드**:
- Texture Atlas
- UV Mapping
- Billboard/Sprite
- Vertex-Index Buffer
- AABB
- Scene Manager
- View Mode
- Show Flag
