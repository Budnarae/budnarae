tags:

클래스에 [[소멸자]]가 정의되어 있지 않을 떄 컴파일러가 자동으로 삽입하는, 아무런 기능도 하지 않는 소멸자.

첫번째 예제는 결과적으로 두번째 예제와 동일하다.

```cpp

class AAA
{
	//empty class
};

```

```cpp

class AAA
{
	public :
		AAA() {}
		~AAA() {}
};

```
